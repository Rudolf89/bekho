# Logotipos de BEKHO

Coloca aquí los dos PNG de la marca. El sistema los detecta automáticamente
(no requiere `npm run build`, se sirven directo desde `public/`).

| Archivo | Uso | Recomendación |
|---|---|---|
| `bekho-logo.png` | Logo completo (insignia con triángulo y figura). Se usa en las pantallas de inicio de sesión y en el menú lateral cuando el tema es oscuro. También como ícono del navegador (favicon). | Fondo transparente. ~512 px de alto. |
| `bekho-horizontal.png` | Logo horizontal (texto BEKHO + emblema). Se usa en el menú lateral con el tema claro. | Fondo transparente. ~120–160 px de alto. |

Mientras estos archivos no existan, la interfaz muestra un logotipo de texto de
respaldo, así que la aplicación nunca queda con imágenes rotas.

Los nombres deben coincidir exactamente (en minúsculas y con extensión `.png`).
